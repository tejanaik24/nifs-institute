# NIFS Student Placement Placeholder Portraits

## Current asset set

- Generated so far: `student-01` through `student-36`
- Formats: one `.jpg` and one matching `.webp` per portrait
- Current total: 36 JPG files + 36 WebP files
- Dimensions: 1448 × 1086 pixels (4:3 landscape)
- Intended use: visual placeholders in NIFS placement-proof sections
- These are AI-generated placeholder portraits, not photographs of identifiable NIFS students or graduates.

## Visual specification

All portraits use the same production treatment:

- Passport/ID-style head-and-shoulders framing
- Subject facing camera with a subtle friendly, confident expression
- Solid neutral soft blue-gray studio gradient background
- Even, balanced diffused direct-flash lighting
- Photorealistic 85mm portrait look with natural skin texture
- No text, watermark, logo, ID-card details, props, CGI, illustration, or dramatic shadows
- Odd-numbered files use a formal light-blue collared shirt
- Even-numbered files use a formal white collared shirt

## Website usage

Use the JPG or WebP asset by its public URL, for example:

```text
/images/placements/students/student-01.jpg
/images/placements/students/student-01.webp
```

Recommended implementation:

- Keep the filename number stable; do not rename files.
- Prefer WebP for normal website delivery, with JPG as the fallback.
- Preserve the 4:3 aspect ratio and centered crop.
- Use `alt` text that clearly says the image is an illustrative placement placeholder, for example: `Illustrative NIFS placement profile placeholder`.
- Do not attach fabricated names, employers, salaries, rankings, reviews, or claims to these portraits.
- Do not present the portraits as real student testimonials or verified placement evidence.
- The remaining sequence, `student-37` through `student-60`, is not generated yet.

## Sequence guidance

When displaying a sequence, use the numeric order from `student-01` upward. The current set was intentionally varied across Indian regional appearances, ages 20–28, hairstyles, grooming, and glasses while maintaining a balanced gender mix.
